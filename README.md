## `> engineering mindset`

```text
idea
  │
  ├── understand the problem
  ├── model the system
  ├── build the smallest real thing
  ├── test the failure modes
  ├── instrument everything useful
  └── ship → learn → iterate
```

> **Build less theatre. Ship more substance.**
